First release.

- Live reading of Markdown files that agents are writing, with the reading position kept in place
- Change marks relative to what you have read, with N / ⇧N navigation and ⌘K to mark all read
- GitHub-flavoured Markdown, Shiki code highlighting, KaTeX math, Mermaid diagrams, GitHub alerts
- Outline sidebar with per-section task progress
- Global shortcut (⌥⌘R) to open the newest Markdown file in your agent folders
- Quick Look extension
- `readout` command line tool, including `readout --hook` for Claude Code hooks
- English and Simplified Chinese
