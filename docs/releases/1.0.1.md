## 1.0.1

Fixes the launch crash from 1.0.0 and a batch of correctness issues.

**Launch crash (1.0.0 regression).** 1.0.0 shipped Sparkle signed ad-hoc while
its embedded XPC services carried mismatched identities — dyld refused to load
the framework and macOS reported the app as incompatible. Sparkle is removed;
updates are checked against the GitHub Releases API (menu item and Settings
toggle kept, no bundled updater code, nothing to sign).

- Update check: manual (**Readout → Check for Updates…**) plus a weekly
  background check, both with English and Chinese UI
- Release workflow no longer pretends to sign/notarize without a certificate

**Correctness.**

- Heading anchors are now unique even when a literal `Notes-1` heading
  collides with a repeated `Notes` (TOC jumps land on the right section)
- Raw-HTML remote media (`<img>`, `<video>`, `<audio>`) goes through the same
  click-to-load gate as Markdown images — documents can't phone home on open
- Autolinked URLs keep balanced trailing parens
  (`…/wiki/X_(film)` links fully)
- `\[…\]` display math renders; ` ```math ` vs ` ```latex ` intent clarified
- Editor links escape `?`/`#` in file names; `readout` CLI handles `-`-named files
- File watcher no longer aliases files that differ only by case
- Change rail ticks are real buttons with VoiceOver labels
- Baselines store a 500-char similarity excerpt (was 2000); scrolling no
  longer rewrites an unchanged baseline file

**Docs.** Keyboard table lists `⌘]`/`⌘[`; design notes describe the 1:1 edit
rule, the real baseline format, and the media privacy gate. The app no longer
claims the default Markdown handler role (`Alternate`).
