Readout 3.9 is simpler and faster: find shows where you are without freezing large documents, each change gets one quiet mark that fades once read, N shows what changed in an edited block, and the app is a quarter smaller.

## New

- **Find shows where you are**: the find field counts matches, such as “3 of 12” or “Not found”, and highlights them in the page. Find no longer lays out the whole document first, so it opens at once even in very large files. An agent writing while you search never moves you or takes your selection; new matches are counted (“– of 12”) and reached with <kbd>Return</kbd>.
- **<kbd>N</kbd> shows what changed**: when <kbd>N</kbd> lands on an edited block, its word-by-word comparison opens, and closes again when you move on. A comparison you open yourself with <kbd>D</kbd> or a click stays open.
- **Copy Link to Section** is in a heading’s context menu, in place of the § that appeared on hover.
- **Code links open in your editor at the line** when the file’s default app is VS Code, Cursor, Zed, Xcode or Sublime Text.

## Improved

### Following an agent

- One mark per change, at full strength. A read change fades away within about a second instead of leaving a grey hairline, and a block that already shows a change no longer flashes as it streams.
- Colour now means unread: ticked task boxes are grey, alerts have no coloured edge, and the next-change button is a plain arrow, with the count in its tooltip and for VoiceOver.
- Messages that pass, such as “Next unread: …” or “No changes since the last commit”, appear above the document and are read by VoiceOver. The window subtitle keeps only what lasts.
- **Open Latest Agent File** has one shortcut, <kbd>⌃⌥⌘R</kbd>, which works inside Readout even with the global shortcut off. A shortcut you chose in an earlier version is kept. With nothing to open, the welcome window explains where files come from instead of an alert.

### Speed

- Readout is about a quarter smaller (29 MB instead of 39 MB), and the download is smaller too.
- New windows open sooner, and each tab uses less memory.
- The first TypeScript block no longer stalls for seconds while it highlights.
- From the second Quick Look preview on, previews open faster.

### Copy

- Copying a few sub-points of a list item pastes them as a list.
- Characters are escaped only where they would otherwise turn into Markdown, so pasted text has fewer stray backslashes.

### On the Mac

- Plainer menus: Show Only Changes, Use Selection for Find, Window ▸ Welcome, and AutoFill, Start Dictation and Emoji & Symbols in Edit are gone.
- Settings is shorter: the global shortcut is a simple on/off switch.
- The whole welcome window accepts a dropped Markdown file.
- About Readout links to the acknowledgements, which open in Readout.
- Front matter is smaller, with lighter keys.

## Fixed

- A crafted file with very deep nesting could still crash Readout or Quick Look on open, and again after relaunch.
- Link definitions inside a disclosure (`<details>`) or next to other blocks were sometimes missed when copying.
- A line with a single `=` inside a list could turn the paragraph above it into a heading.

## Privacy

- **Download Update** hands the new version’s disk image to your browser. Readout no longer writes anything to your Downloads folder.
- Copies over 100,000 characters go to the clipboard as Markdown only (was 500,000).
