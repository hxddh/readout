## 2.0.0

Link navigation that lands where you meant, follow semantics that respect
where you are, and a full review pass over code, docs, and signing.

**Cross-file links with fragments.** `other.md#section` now opens the file
*and* scrolls to the section; `#section` in the same document scrolls in
place. Fragment matching is GitHub-style (percent-decoding, case-insensitive
slug fallback), and a link-opened file's fragment wins over the restored
reading position.

**Follow semantics.** Sitting at the end of a document still follows the
agent like a terminal — but only when the change is at or below the
viewport. An insertion at the top no longer yanks a bottom-dwelling reader;
the reading anchor is restored instead. Covered by patch-engine tests
(insert order, anchor stability, top-insert vs append, fragment scroll).

**Stability under rapid writes.** Overlapping parses from fast successive
writes are coalesced: one in-flight parse, queued completions share a
generation, stale results are dropped, and a write that lands mid-parse
triggers exactly one follow-up read from disk.

**Review batch.**

- Failed background update checks no longer push the weekly timer forward —
  one offline launch used to silence updates for another week
- Change-rail ticks are exposed to assistive tech (labeled buttons in a
  navigation landmark, not `aria-hidden`)
- Settings, Welcome, and sidebar strings all localized; Chinese coverage 100%
- Drag-and-drop and file opening accept Markdown files only
- `tools/sign.sh` drops dead Sparkle special-casing; the inside-out
  same-identity signing that fixed the 1.0.0 launch crash is unchanged

**Docs.** Release notes for every version live under `docs/releases/`.
Ad-hoc signature (no Developer ID): first launch needs
**System Settings → Privacy & Security → Open Anyway**, as before.
