Readout 4.0 reads better and holds still. The text grows with your window and the outline appears when there is room. Code is already coloured when you see it, and the page doesn't move once it's on screen.

## New

- **The text grows with the window.** In a larger window it gets bigger, up to 1.25 times your size in a window 1800 px wide or more, so the text column never sits in wide empty margins. Lines stay about as long as in 3.9 at every size. <kbd>⌘+</kbd> and <kbd>⌘−</kbd> still adjust it, and <kbd>⌘0</kbd> goes back to the automatic size. View ▸ Wide Text is gone.
- **The outline shows itself when there is room.** In a wide window it appears beside the page, and as the window narrows it hides. Showing or hiding it yourself, with the button, <kbd>⌃⌘S</kbd> or by dragging the divider, holds for that window. Each new window starts from its own width.

## Improved

- **Code is coloured in the background.** Scrolling documents full of code is smooth, a jump into a very large code block takes under two seconds instead of over a minute, and such documents use far less memory.
- **Code is coloured before you see it.** A document opens with the code on screen already coloured, and a jump, an outline click or a find result lands on coloured code.
- **The page doesn't move once it's shown.** Opening a document, switching tabs and jumping all land in one go, including next to formulas. When a diagram or image is still loading where you land, it takes its full size once it's ready: what's below it moves down once, and the text you're reading stays put.
- **Inline code reads with the sentence around it.** It is slightly larger, sits on a fainter background and has less padding.
- **A paragraph that ends with a colon sits close to the list it introduces.**
- **Tables use their space better.** Short cells and identifiers stay on one line while there is room. Long file paths wrap after a slash, so a description column beside them keeps its width. A table that only fits with its short cells wrapped can widen into the margin.
- **Open Latest Agent File is always <kbd>⌃⌥⌘R</kbd>.** If you had picked <kbd>⌥⌘R</kbd> or <kbd>⌃⌥R</kbd> in an earlier version, it is now <kbd>⌃⌥⌘R</kbd>.

If you are updating from Readout 3.5 or earlier, files you had open start fresh, once: their reading positions and unread marks are not carried over. The same applies to a file that still had changes unread since then.
