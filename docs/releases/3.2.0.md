## 3.2.0

Readout now opens what your agents write without being asked, and without getting in your way.

## New

- **New documents open on their own.** When an agent creates a new Markdown document in one of the folders listed in Settings (Claude Code's `~/.claude/plans` is there by default), Readout opens it in the background, as a tab behind the one you are reading. Edits to files that were already there, such as a README, do not open anything. A burst of new files opens at most three, and a file you close does not reopen until Readout is relaunched. Nothing to install or turn on.
- **A new icon.**

## Improved

- **Readout no longer takes focus on its own.** A document that opens by itself leaves your terminal in front and the document you were reading selected, and `readout -b` (or `open -g`) now really keeps Readout in the background.
- <kbd>D</kbd> now walks down the screen: each press opens the next closed comparison in view, and once all of them are open, the next press closes them.
- Korean text stored with separate jamo (as some tools write it) compares syllable by syllable in the word-level change view, like other Korean text.
- **Install Command-Line Tool** is gone from the menu: agents need no setup, since watched folders are enough. The `readout` script is still inside the app; the README shows how to link it if you want it.

## Fixed

- In large documents, a link to a heading or footnote in the same document sometimes did nothing when clicked right after scrolling; clicking a tick on the change rail could do the same.
