Readout 4.1 gives your documents room. The text column is wider, wide code and tables use the space beside it, and a click in a document never runs anything.

## New

- **View ▸ Text Width.** Standard is about 110 characters of English (52 of Chinese) at Actual Size, wider than 4.0's column. Wide is wider still, for long tables and paths. The choice is kept.
- **Readout ▸ Install Command Line Tool…** gives you the one command that links `readout` into `~/.local/bin`, ready to paste into Terminal. Readout itself still writes nothing.

## Improved

- **A wide window shows more, not larger text.** The text still grows a little with the window, up to 1.12 times your size (it was 1.25), and long code and wide tables now use the room beside the column, up to about 1.4 times its width.
- **Unread marks on very long blocks.** A log or table thousands of lines long is marked read as you scroll through it; before, it could stay unread for good.
- **The outline follows you into deep sections.** Below a level 5 or 6 heading, the outline still highlights the section you are in.

## Fixed

- Turning code wrapping on or off keeps your place instead of jumping thousands of pixels.
- Formulas typeset together above your place no longer nudge the text you are reading.
- A heading such as "MMD 1" is no longer removed when a diagram is drawn, and raw HTML in a document can no longer take the place of Readout's own elements.
- A document containing certain private-use characters could make Readout quit. It now shows them as �.
- A file in Latin-1 or Windows-1252 no longer loses its last characters; it opens as another encoding, with the notice that says so.
- An image path that is a named pipe no longer freezes the document, and large local images no longer stall the window.
- Opening a document at a section (`readout plan.md#risks`) while its window is still loading now lands on the section.
- An image whose file name contains `%` followed by two digits or letters now shows.
- A README deep in a large watched project no longer opens by itself the first time an agent edits it.
- When a file and a link to it were both open, closing one could leave the file openable twice.
- Several windows opening in the same git repository no longer wait for each other.
- The "Readout x.y.z Is Available" menu item names the newest version found.
- `readout --hook` opens files Claude Code creates, whose hook data holds `null` values.

## Privacy

- **Links never run anything.** A link to an application, a script, an installer, a disk image or another executable shows it in Finder instead of opening it. Links out of a document open only for `http`, `https` and `mailto`; any other kind (an app's own link scheme) is refused, with a notice.
- Remote images are also refused from documentation and Teredo address ranges, and one slow image no longer holds up the others' checks.
