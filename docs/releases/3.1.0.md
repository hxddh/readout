## 3.1.0

Readout gets simpler, renders more of GitHub-flavoured Markdown the way GitHub does, keeps up with large documents, and now shows exactly which words an agent changed.

## New

- **See what changed in a paragraph.** Click the bar beside an edited block, or press <kbd>D</kbd>, to see the words that changed since you last read it: removed text struck through, added text highlighted. Chinese, Japanese and Korean compare character by character. Click again to hide it. Your reading position does not move.
- **Removed text in full.** The marker left where text was removed now opens to the whole removed passage as you last read it, not just its first lines.
- **Footnotes.** `[^1]` references and their definitions render as on GitHub: numbered in order of first reference, with links to the note and back (one per reference), in a notes section at the end.
- **Collapsible sections.** `<details>` with Markdown inside renders as one block that folds and unfolds, code and lists included.
- **More links.** `www.` addresses and email addresses become links, as on GitHub.
- **Code wrapping.** A **Wrap** button on code blocks wraps long lines; the choice is remembered and applies to every window.

## Improved

- Large documents update much faster: only the part of the file that changed is parsed again (a 1 MB file updates in a fraction of the time it took).
- Large documents (over a few hundred blocks) look the same as small ones: block spacing no longer widens, and change marks, section links and list numbers are no longer cut off at the left edge.
- Tables that fit keep their header row in view while you scroll through them, just below the toolbar; wide tables keep their first column in view while you scroll sideways.
- Mermaid diagrams use the page's colours in light and dark mode; a diagram that cannot be drawn says why and shows its source.
- Chinese text: stricter line breaking around punctuation, and doubled spacing between adjacent full-width punctuation is trimmed.
- Long file paths and identifiers in inline code wrap inside the text column instead of running past it.
- Printing: no interface elements, wrapped code, folded sections printed open, and tables, code and diagrams are not split across pages.
- A block that is edited and then changed back to what you read is no longer marked as changed; a checkbox you have not seen ticked stays marked.
- Simpler window: word count and reading time are gone from the subtitle and sidebar (the subtitle shows task progress when the document has tasks), and the welcome window no longer lists recent files — they remain in **File ▸ Open Recent**.

## Fixed

- Code blocks were occasionally coloured entirely as a comment; highlighting is now the same every time a document opens.
- The update check no longer treats a pre-release as newer than its final release, and offers the final release to someone on a pre-release.

## Privacy

- Remote images that you load by clicking are refused as soon as they exceed 20 MB, before they finish downloading, and images on `localhost` or your local network are never fetched.
