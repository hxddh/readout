Readout 5 remembers how your documents changed. It keeps the versions of every file you read, lets you compare with any of them and open any of them, gathers everything waiting for you in one place, and opens files faster.

## New

- **Reading history.** Readout keeps each version of a document it sees, the state a file settles in after an agent writes it, for 30 days.
- **View ▸ Compare with Earlier Version** marks what changed since any version Readout kept, each listed with when it was seen and how much differs now. ⌘Z brings back what you had read.
- **View ▸ Open Earlier Version** opens a version read-only in a window of its own, marked with what changed in it.
- **View ▸ Unread Changes** lists every document waiting for you, newest first: open ones with unread changes or not looked at yet, and files in your agent folders that changed since you read them. Choose one to go to its first change.
- **Drag the column's edge** to make the text as wide as you like, in every window. Double-click the edge to go back to Standard.
- **Setting up, on the welcome window.** Add the folders your agents write in and install the `readout` command from one place, each step checked once done.

## Improved

- **Files open faster** when Readout is already running: the page that shows a document has its fonts ready before you open one.
- **Very long code blocks** (a whole log, a generated file) show their first 3,000 lines and a button for the rest, so a document holding one opens and scrolls without a long pause and uses far less memory. Copy, Find and printing still use every line.
