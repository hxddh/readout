Readout 5.1 is simpler and quicker: fewer menu items, one way to compare, and less work while an agent writes.

## New

- **Help ▸ Performance** shows how long your last opens and live updates took on your Mac, with a button to copy the numbers.

## Improved

- **View ▸ Compare With** puts every comparison in one place: Last Commit first, for a file in a git repository, then the versions Readout saw, each named by when it saw them. ⌘Z still brings back what you had read.
- **Less writing to disk while an agent streams a long document:** a document's history is saved at most every 5 seconds, and when you close it or quit, instead of on every change. Readout keeps the last 20 versions of each document.
- **The outline** keeps each heading on one line; hover over it for the whole heading.
- **The welcome window** is shorter and says "Watching 1 agent folder" when there is one.

## Fixed

- A long code block you expanded with **Show more lines** stays expanded when an agent edits it.
- Fixed rare crashes when the system reported a change to the window's tabs, its layout or the Quick Look preview's appearance from a background thread, and when a file was dropped on the welcome window.

## Removed

- **View ▸ Open Earlier Version** and **View ▸ Unread Changes.** Compare With shows what changed since any version, and the tab dots, the Dock badge and N lead you to the documents waiting for you.
- **Dragging the column's edge.** View ▸ Text Width ▸ Standard and Wide remain; a width you dragged in 5.0 becomes Standard.
