## 3.4.0

Readout 3.4 is faster with large documents, looks more finished, and is easier to use day to day.

## Improved

### Faster

- Updates to large documents are more than twice as fast, and new content is parsed on several cores at once.
- The page applies an update in one pass instead of re-measuring after every changed block; a 20-block update to a 1 MB document is several times faster.
- Readout starts reading a file as soon as it changes, instead of waiting a fixed 80 ms first.
- Diagrams load only the parts they need, less than half the code they loaded before.

### Looks

- The top of a document no longer sits under the toolbar, and the "rewritten" notice and the change rail stay below it.
- Dark mode opens dark, without a white flash.
- Wide tables keep short cells on one line; number columns line up on the right; an empty header row is no longer drawn.
- Even spacing after code blocks and around display math, and inside quotes and callouts.
- Links are underlined, so they stand out from text in dark mode too. Callouts have clean corners. Smaller headings are easier to tell apart, and nested numbered lists use i. and a. like GitHub. Long numbered lists keep their numbers clear of the margin.
- Edited blocks you haven't read stay visible with the Graphite accent colour, and the page follows Increase Contrast.
- The removed-text popup and the code block buttons look cleaner; the outline sidebar only scrolls when the current section is out of view and indents sections under a single title correctly.
- The toolbar no longer shifts when changes are read, and the width button shows its state.

### Easier

- If a file is deleted, unreadable or decoded with a fallback encoding, the window subtitle says so, even with the sidebar hidden.
- Tabs show the document's title, and Open Recent tells same-named files apart and greys out files that are gone.
- **Copy Link to Section** copies the full path, ready to paste to an agent.
- **Open in Editor** (⌘E) opens your text editor even when Readout is your default Markdown app.
- The global shortcut is now <kbd>⌃⌥⌘R</kbd> by default, so it no longer takes <kbd>⌥⌘R</kbd> from Safari and Xcode. If you chose a shortcut yourself, it is kept.
- Claude Code's `~/.claude/plans` is watched from the start, even if it doesn't exist yet, and agent folders created later are picked up on their own.
- Help opens the keyboard shortcuts, in Chinese for Chinese users; the change button's tooltip mentions <kbd>D</kbd>.
- Clearer, more consistent wording in English and Chinese.

## Fixed

- Inline math such as `\(O(n)\)` renders again.
- Readout keeps following the end of a document when the agent writes on into the last paragraph or code block, and after you resize the window or change the text size.
- A file briefly emptied and written back keeps your place, also when it is written back in parts.
- Resizing the window right after a jump no longer takes you back to where you were before it.
- `$…$` inside indented code in a quote no longer changes the code, and a `$$` in a list no longer swallows the next item.
- English lines mentioning a Chinese word keep English line spacing.
- Images given with `srcset` show.
- A link such as `latest.md` pointed at a file that doesn't exist yet picks the file up when it is written.
- Find (including <kbd>⌘G</kbd>) finds text anywhere in long documents and no longer leaves long documents slower afterwards.
- Changing agent folders in Settings no longer freezes the app.
- VoiceOver reads each heading by its own name.
