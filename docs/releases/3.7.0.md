Readout 3.7 fits your agent workflow more closely: quote a passage back to your agent, move between documents with unread changes, and pick up where you left off after relaunching. It also typesets Chinese and Japanese better and updates large documents much faster.

## New

- **Copy as Quote** (<kbd>⇧⌘C</kbd>, also in the context menu): copies the Markdown of the selected blocks as a quote, followed by the file and lines, such as `— src/plan.md#L12-L18 (§ Rollout)`. Paste it into your agent to point at exactly what you mean.
- **<kbd>N</kbd> across documents**: when nothing is left unread in the current document, <kbd>N</kbd> brings forward the next open document with unread changes. The Dock icon shows how many documents have unread changes.
- **Windows come back**: reader windows, their tabs, and which tab was selected are restored after relaunching. This follows the system setting “Close windows when quitting”. Every new window opens at the size you last used.
- **First open against the last commit**: the first time you open a file that is in a git repository, its changes since the last commit are marked as unread (or, if most of it changed, Readout says the file was rewritten). This needs Xcode or the Command Line Tools; without them Readout stays quiet and never asks you to install anything.
- **Plans show their project**: a plan opened by the `readout --hook` agent hook shows its project's name in the window subtitle, and links in it to files in the project open.
- **Download Update** in the update alert saves the new version's disk image to Downloads and shows it in Finder.
- **Edit ▸ Speech** reads the selection aloud, or the whole document when nothing is selected.
- **About Readout** lists the open-source software Readout is built with, along with each license.

## Improved

### Following an agent

- A short document that fits in the window counts as read while you watch it, and Readout keeps following it as it grows.
- Unread counts and dots no longer flicker up for changes you read as they arrive.
- A run of new blocks is one stop for <kbd>N</kbd>. <kbd>N</kbd> continues from wherever you jumped to with the outline, a link, or Home/End, and the change it lands on pulses briefly.
- When an agent rewrites the file, you stay at your section, or go to the top, instead of being taken to the new end.
- While you type in the outline or the find field, changes on screen still count as read.
- An agent writing the last paragraph no longer briefly shows “1 block removed”.
- Changes stay marked correctly after relaunching when a file was trimmed and then edited.
- Tabs with the same title also show the file name, and a tab opened in the background keeps its dot until you look at it.
- **Open Latest Agent File** (<kbd>⌃⌥⌘R</kbd>) goes to the newest agent document waiting for you, whether it has unread changes or was opened in the background. <kbd>⌘]</kbd> and <kbd>⌘[</kbd> work whenever any open document has unread changes.

### Reading

- Chinese and Japanese text: line breaks inside a paragraph no longer leave a gap, and bold or emphasis such as `**注意：**这里` now works next to full-width punctuation.
- Emphasis dots are drawn without changing line breaks or line spacing, and they print.
- Tables wrap short cells to fit the window before they start to scroll sideways. In wide windows, scrolling tables extend to the right only.
- Inline code followed by Chinese punctuation no longer leaves a gap, and output in terminal transcripts is shown in grey.
- Bulleted and numbered lists share one indent, and two-digit numbers no longer reach into the margin.
- Paths to code are real links for VoiceOver and the keyboard: <kbd>Tab</kbd> to one and press <kbd>Return</kbd> to open it. VoiceOver announces which change <kbd>N</kbd> landed on.
- Code blocks you jump to are highlighted before they appear.
- The toolbar fades softly into the document as it scrolls under it.
- <kbd>⌘E</kbd> opens your editor closer to the line you are reading.

### Speed

- Live updates to large documents are much faster: an agent appending to a 1 MB document now costs a fraction of what it did.
- The page does less work per update, so following a very large document scrolls more smoothly.
- The first code block in a new window highlights quickly, without making opening windows slower.
- Quick Look previews large files faster.

### On the Mac

- Chinese menus use 拷贝 and 边栏, as macOS does.
- **View ▸ Show What Changed** is available whenever a document is open, and beeps when there is nothing to compare.
- The welcome window's text is easier to read.

## Fixed

- Links to Sublime Text open the right file when its path contains `&`, `=` or `+`.
- A folder created while Readout is running is picked up reliably.
- A table followed by a tab-indented line looked different after a live update than after reopening the file.
- Printing right after opening a document printed an empty page.

## Privacy

- Until Readout is notarized, macOS asks again after each update before Readout may read files in Documents, Desktop or Downloads, or ask Xcode to open a file at a line. The README explains why.
