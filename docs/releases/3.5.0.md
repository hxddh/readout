## 3.5.0

Readout 3.5 is calmer at the top, reads better at any text size, and responds the way a Mac app should.

## Improved

### A lighter window

- The top of the window is slimmer: the document starts just below the toolbar, and the subtitle only appears when it has something to say (a file problem or task progress). A window without tabs still shows the folder, so same-named files stay distinguishable; with tabs, the folder is in the tab's tooltip.
- The text-width button is gone from the toolbar. Switch width with **View ▸ Wide Text** (<kbd>⌥⌘\</kbd>).
- The next-change button appears only when there are unread changes, as a plain arrow. The search field is narrower.
- New windows follow your **Prefer tabs** setting in System Settings. Documents that open on their own still join as tabs.

### Reading

- Changing the text size keeps the same number of characters per line, as in Safari Reader.
- Code that runs past the column shows a soft edge, so you can tell it scrolls.
- Text selection uses the system's colour and turns grey when the window is in the background.
- Headings wrap into balanced lines, and paragraphs avoid a lone last word where macOS supports it.
- Emphasis in Chinese and Japanese is shown with emphasis dots instead of slanted characters.
- Numbered lists keep two-digit numbers inside the column, diagrams scale with the text size, ticked tasks no longer grey their unticked sub-items, and struck-through text and highlights are easier to read in both themes.

### Using it

- **Undo Mark All as Read**: <kbd>⌘Z</kbd> brings back the marks after <kbd>⌘K</kbd>.
- Clicking a heading in the outline lands on it and highlights it, every time, and returns the keyboard to the document.
- <kbd>End</kbd>, <kbd>⌘↓</kbd>, <kbd>Home</kbd> and <kbd>⌘↑</kbd> reach the end and start of long documents. <kbd>J</kbd>/<kbd>K</kbd> scroll like the arrow keys, and Caps Lock no longer reverses <kbd>N</kbd> and <kbd>G</kbd>.
- Removed text can be selected and copied; <kbd>Esc</kbd> closes it and open comparisons.
- Changes that arrive while Readout is in the background wait until you have actually looked at them before counting as read.
- <kbd>N</kbd> with nothing unread gives a beep instead of doing nothing.
- The change rail's ticks are easier to click.
- The welcome window explains which folders open on their own.

## Fixed

- **Open Link** in the context menu no longer blanks the window; links to websites can still be copied.
- Tables that had to scroll in a narrow window fit again when the window gets wider.
- A short document no longer jumps after the agent adds something at the top, and the reading place survives diagrams and formulas rendering during a refill.
- A stray quote in an HTML block no longer hides the text and image after it.
- A document whose first heading is an image or empty shows its file name as the tab title.
- Version numbers such as `1.0.0` are no longer right-aligned as numbers.
- VoiceOver reads headings with math and footnotes correctly.
- In Quick Look, buttons that can't work there (copy, section link, load image) are hidden.
- Readout no longer checks every 2 seconds for an agent folder that doesn't exist yet; it is noticed as soon as it is created.
- The global shortcut no longer says there are no recent files right after a folder appears.
- **Open Recent** tells apart same-named files in same-named folders.
