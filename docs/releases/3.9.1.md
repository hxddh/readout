Readout 3.9.1 makes long documents smooth again: scrolling no longer shows blank areas or stutters, your place holds while an agent writes elsewhere, and code is coloured the moment it appears.

## Improved

- **Scrolling large documents is smooth**: no blank areas and no stutter while scrolling, from a few hundred kilobytes up to several megabytes.
- **Diagrams no longer freeze a long page** while they draw.
- **Find stays quick in large documents**: <kbd>Return</kbd> moves to the next match at once and selects it at any size, and highlights repaint only where they change.
- **Switching between light and dark is faster** in documents with a lot of code.
- **Large documents use less memory.**
- **New windows open as fast as in 3.8**, and respond to the first click or key sooner.

## Fixed

- The text you were reading could move when an agent added, replaced or removed content further up or down the document.
- On some opens, code in a few languages showed uncoloured for a moment before its colours appeared.
- After following a link or footnote, or pressing <kbd>N</kbd>, code on screen could show uncoloured for a moment.
- A wide table could shift as it scrolled into view.
