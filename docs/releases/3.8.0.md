Readout 3.8 copies Markdown the way it was written, follows large documents without stalling, and fits the agent workflow more closely, with Compare with Last Commit, links that open as tabs and new agent documents that count as waiting.

## New

- **Copy keeps the Markdown**: <kbd>⌘C</kbd> puts the selection's Markdown on the clipboard as plain text, so pasting into a terminal, an agent or an editor keeps headings, emphasis, code, lists, tables and links, with the link definitions they use. Whole blocks copy exactly as written in the file. Rich apps such as Notes, Mail or Slack still get formatted text. Dragging a selection carries the same Markdown. Pasting into a plain-text field now shows Markdown marks such as `**` and `- `; very large selections (over 500,000 characters) copy as Markdown only.
- **View ▸ Compare with Last Commit** marks what changed in the open document since the last git commit. <kbd>⌘Z</kbd> undoes it.
- **Links to other documents open as tabs** in the same window, in front; <kbd>⌘W</kbd> takes you back.
- **New agent documents wait for you**: a document an agent opened in the background, that you have not looked at yet, now counts in the Dock badge, for <kbd>N</kbd> across documents and for <kbd>⌘]</kbd>/<kbd>⌘[</kbd>.
- **Copy as Quote without selecting**: after <kbd>N</kbd> lands on a change, <kbd>⇧⌘C</kbd> quotes that block.
- **More agents**: `readout --hook` also accepts Cursor's hook input, and the README shows how to set it up for Cursor and Gemini CLI.

## Improved

### Following an agent

- Edits an agent makes above where you are reading no longer freeze large documents, outline jumps in them are much faster, and live updates near link definitions and footnote syntax cost a fraction of what they did.
- Following the end of a growing document no longer loses the end.
- Scrolling up through parts of a long document you have not seen yet jumps far less.
- Tabs restored after relaunching remember whether you had looked at them, so finished documents no longer come back with a dot.
- Tabs with the same title show the file name first.
- Launched as a login item, Readout opens without the welcome window.

### Reading

- Chinese and Japanese emphasis dots are drawn whole instead of as thin dashes.
- Long prose and prompts in plain-text code blocks (no language, `text` or `markdown`) now wrap instead of scrolling sideways. Code, terminal output and aligned tables keep their layout.
- Chinese quotation marks, dashes and ellipses use the full-width PingFang forms.
- Front matter is shown as aligned keys and values.
- <kbd>Tab</kbd> moves between links.

### On the Mac

- **Download Update** shows its progress in Finder and the Dock, and the update notice in the app menu downloads the same way.
- The disk image shows where to drag Readout and how to open it the first time.
- Quick Look loads its page while the file is being read.
- Watching files skips build and dependency folders, using less energy while agents build.

## Fixed

- Opening a file with very deep nesting (hundreds of levels of quotes or lists) crashed Readout, and relaunching reopened it and crashed again.
- Bold or emphasis followed by an invisible variation selector, common in Chinese and emoji text, could lose its asterisks.
- Copy as Quote dropped the trailing spaces of a hard line break and the `---` around front matter.
- Code references written relative to the repository root were not found in documents deep inside it.
- The first open of a file committed empty, or committed as UTF-16, was not compared with the commit. A first open of a file mostly rewritten since the commit now says “Rewritten since the last commit”, and a slow git no longer holds up opening.
- Several rare cases where a live update showed a block differently from reopening the file.

## Privacy

- Copied rich text never makes the app you paste into load remote images, and links in it are limited to web, mail and in-page addresses. Markdown links to `javascript:` and similar addresses are no longer clickable.
