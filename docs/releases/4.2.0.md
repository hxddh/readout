Readout 4.2 lets the text use your window. The column now grows and shrinks with the window instead of stopping at a fixed width.

## Improved

- **The column follows the window.** It fills the window less a narrow margin on each side, up to about 175 characters of English (80 of Chinese) at Actual Size, which a window about 1600 px wide reaches. Narrow the window and the column narrows with it.
- **View ▸ Text Width ▸ Wide has no limit.** The text fills the whole window, whatever its size.
- **The outline appears sooner.** It shows beside the page once the column beside it still holds about 110 characters, from a window of about 1130 px at Actual Size.
- **Wide code and tables** use the room beside the column only once the column has stopped growing, so they line up with the text in every other window.
