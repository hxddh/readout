# Readout 快捷键

**等你查看**的文件：有未读变更，或在后台打开后你还没看过。它的标签页上有圆点，程序坞图标上的数字是等你查看的文件数。

## 阅读

| 按键 | 作用 |
| --- | --- |
| <kbd>N</kbd> / <kbd>⇧N</kbd>（或 <kbd>⌘]</kbd> / <kbd>⌘[</kbd>） | 下一处 / 上一处未读变更（停在修改过的段落上时显示具体变更，离开即收起），读完后前往下一个等你查看的文件 |
| <kbd>D</kbd> | 显示 / 收起屏幕上各处修改的具体变更（也可用**显示 ▸ 显示具体变更**） |
| <kbd>⌘K</kbd> | 全部标为已读（<kbd>⌘Z</kbd> 可撤销） |
| <kbd>J</kbd> / <kbd>K</kbd> | 向下 / 向上滚动 |
| <kbd>G</kbd> / <kbd>⇧G</kbd>（或 <kbd>⌘↑</kbd> / <kbd>⌘↓</kbd>） | 跳到开头 / 结尾 |
| <kbd>Esc</kbd> | 关闭展开的变更对比或删除内容 |
| <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> | 下一个 / 上一个链接或文件路径 |

**显示 ▸ 与上次提交比较**会标出自文件上次 git 提交以来的变更（<kbd>⌘Z</kbd> 可撤销）。

## 文件

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘O</kbd> | 打开 Markdown 文件 |
| <kbd>⌃⌥⌘R</kbd> | 打开最新的 Agent 文件，等你查看的优先，在任何应用中都可用（可在设置中关闭） |
| <kbd>⌘E</kbd> | 在编辑器中打开，定位到正在阅读的行（或选中的内容） |
| <kbd>⇧⌘R</kbd> | 在访达中显示 |
| <kbd>⌘C</kbd> | 拷贝为 Markdown（富文本应用中带格式） |
| <kbd>⇧⌘C</kbd> | 拷贝为引用，附文件与行号，交给你的 Agent |
| <kbd>⌥⌘C</kbd> | 拷贝文件路径 |
| <kbd>⌘P</kbd> | 打印 |
| <kbd>⌘W</kbd> / <kbd>⌥⌘W</kbd> | 关闭 / 全部关闭（从链接打开的文件：返回链接所在的标签页） |

## 查找与显示

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘F</kbd> | 查找 |
| <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> | 查找下一个 / 上一个 |
| <kbd>⌘+</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> | 放大 / 缩小 / 实际大小 |
| <kbd>⌃⌘S</kbd> | 显示 / 隐藏边栏 |
| <kbd>⌃⌘F</kbd> | 全屏 |
| <kbd>⌘,</kbd> | 设置 |

指向源文件的链接会在编辑器中打开并定位到该行：`src/app.ts:42`、`src/app.ts:42:7`，或 GitHub 风格的 `src/app.ts#L42`。编辑器是该文件的默认应用（VS Code、Cursor、Zed、Xcode 和 Sublime Text 会定位到行），或在设置中选定的编辑器。
