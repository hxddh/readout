# Readout 快捷键

## 阅读

| 按键 | 作用 |
| --- | --- |
| <kbd>N</kbd> / <kbd>⇧N</kbd>（或 <kbd>⌘]</kbd> / <kbd>⌘[</kbd>） | 下一处 / 上一处未读变更；本文档已无未读时，前往下一个有未读变更、或在后台打开后尚未查看的文档 |
| <kbd>D</kbd> | 从上到下依次显示视野内修改段落的具体变更；全部显示后再按一次收起（也可用**显示 ▸ 显示具体变更**） |
| <kbd>⌘K</kbd> | 全部标为已读（<kbd>⌘Z</kbd> 可撤销） |
| <kbd>⇧⌘K</kbd> | 只看变更 |
| <kbd>J</kbd> / <kbd>K</kbd> | 向下 / 向上滚动 |
| <kbd>G</kbd> / <kbd>⇧G</kbd>（或 <kbd>⌘↑</kbd> / <kbd>⌘↓</kbd>） | 跳到开头 / 结尾 |
| <kbd>Esc</kbd> | 关闭展开的变更对比或删除内容 |
| <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> | 下一个 / 上一个链接或文件路径 |

**显示 ▸ 与上次提交比较**会为 git 仓库中的文件标出自上次提交以来的变更（<kbd>⌘Z</kbd> 可撤销）。程序坞图标上的数字是等你查看的文档数：有未读变更的，或在后台打开后尚未查看的。

## 文件

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘O</kbd> | 打开 Markdown 文件 |
| <kbd>⇧⌘O</kbd> | 打开最新的 Agent 文件：已打开且有未读变更、或在后台打开后尚未查看的文档优先 |
| <kbd>⌃⌥⌘R</kbd> | 在任何地方打开最新的 Agent 文件（全局快捷键，可在设置中更改或关闭） |
| <kbd>⌘E</kbd> | 在编辑器中打开当前文件，定位到正在阅读的行（或选中的内容） |
| <kbd>⇧⌘R</kbd> | 在访达中显示 |
| <kbd>⌘C</kbd> | 将所选内容拷贝为 Markdown（完整段落与文件原文一致）；支持富文本的应用粘贴为带格式文本 |
| <kbd>⇧⌘C</kbd> | 拷贝为引用：所选段落（未选中文本时为 <kbd>N</kbd> 跳到的段落）的 Markdown 源文本，附文件行号与章节 |
| <kbd>⌥⌘C</kbd> | 拷贝文件路径 |
| <kbd>⌘P</kbd> | 打印 |
| <kbd>⌘W</kbd> / <kbd>⌥⌘W</kbd> | 关闭 / 全部关闭（从链接打开的文档：返回链接所在的标签页） |

## 查找与显示

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘F</kbd> | 查找 |
| <kbd>⌘G</kbd> / <kbd>⇧⌘G</kbd> | 查找下一个 / 上一个 |
| <kbd>⌘+</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> | 放大 / 缩小 / 实际大小 |
| <kbd>⌥⌘\</kbd> | 窄栏 / 宽栏 |
| <kbd>⌃⌘S</kbd> | 显示 / 隐藏边栏 |
| <kbd>⌃⌘F</kbd> | 全屏 |
| <kbd>⌘,</kbd> | 设置 |

指向源文件的链接会在设置中选定的编辑器里打开并定位到该行：`src/app.ts:42`、`src/app.ts:42:7`，或 GitHub 风格的 `src/app.ts#L42`。
